## 已完成

- 67 项自动测试全部通过：状态语义、共享资源、切分、输入变化、错误处理、模型证据、搜索预算恢复和官方运行时。
- 通过未经修改的官方 AgentHack SDK 1.1.1 完成 17 项真实模型端到端测试：14 个公开 256-rank 样例、2 个公开小例、1 个同名实例共享容量变化用例。
- 每例 SDK 均记录 1 次 LLM 调用；模型提出的首候选均实际构造并通过回放；最终方案再次独立校验有效。
- 最后增加前置校验和首候选预算保护后，用全部 14 个真实模型建议做回归，全部有效，最终通信耗时与之前真实测试一致。
- 官方小例的给定输出回放为 AG 66.836 μs、AR 100.904 μs；程序自动改选 split=2 的 AR 为 68.136 μs。
- 固定同一实例 ID，将小例 ingress 共享容量改为 0.25 GB/s 后，重新调用模型，模型输入摘要与请求体均变化，最终通信时间重新计算为 263.444 μs。
- 检查代码、测试与报告中未复制实际 API Key；`.env` 不在镜像构建内容中。

## 证据与边界

- `artifacts/unit-tests.log`：自动测试日志。
- `artifacts/runtime/summary.json`：真实 SDK / LLM 测试汇总。
- `artifacts/runtime/*.json`：实际模型输入、响应策略、候选验证与采纳证据、完整 solution。
- `artifacts/budget-regression.json`：最终代码的模型策略回归。
- `artifacts/validation.json`：汇总及最终源代码 SHA-256。

本地测试使用宿主机 Python 3.10 和从官方镜像提取的原版 SDK；最终基础镜像为 Python 3.11。没有执行任何 Docker 命令，没有在容器内实测或强制施加 1 CPU / 1024 MiB 限制。
公开样例不是正式冻结实例，且未提供官方 Judge 可执行文件及评分锚点。因此本记录不能称为官方判题通过，也不能给出正式分数。
