# AgentCC 1.8 独立源码快照

这是源码包，不是已导出的容器镜像。包含 Python 服务、C++ 容量核心、测试和文档；`manifest.json` 保存逐文件 SHA-256。生产源码与最终126次真实 SDK 对照一致。

本机已有官方 `agenthack/base:1.1.1` 后，可以在本目录构建：

```bash
docker build --platform linux/amd64 -t agentcc-team:1.8 .
```

构建阶段需要访问软件源安装 g++，使用官方基础环境的 Python 编译扩展。最终镜像不额外包含编译器，非 root 运行官方 AgentRuntime，并要求 C++ 成功加载。没有在本项目开发过程中执行 Docker。

真实 Key 不在包内，通过平台环境变量或本机 `.env` 提供。模板见 `.env.example`。扩展在构建时生成，源码包不携带开发机二进制。

完整测试工具需要原开发项目的公开样例、官方 SDK、历史源码与原始记录；这些不在独立源码包中。README、THEORY、VALIDATION 保留发布时内容，其中实验链接需要在完整项目根目录查看。

本轮1.8相对1.7的请求CPU减少27.26%，调度相同；真实完整请求5.920→6.021秒，没有证明端到端加速。1.8未获平台成绩，1.7快照和源码包保持原样。
