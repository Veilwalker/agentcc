# 1.11 验证说明

1.11 保持 1.9（源自1.6）的调度算法，仅增加 C++ 最短路径计算。固定原始模型回答的 56 次 SDK 完整请求全部有效，同提示、同最终调度；平均请求 2.011 → 1.906 秒。另有 56 次真实模型 SDK 请求用于比较 1.9 与 1.11。

官方 Python 3.11 / AgentHack SDK 下发现 430 项测试，427 项通过、3 项因历史证据未在快照内打包而跳过。快照测试临时引用完整项目的材料和1.4历史代码，不修改生产源码；这些测试辅助文件不进入发布包。

测试包含 C++ 容量差分、最短路径与 Python 参考实现的差分、方向/共享资源/轮初持有语义、非法输入和 SDK 协议。旧 Python 堆监视测试现在显式针对 Python 参考分支运行；原生路径由独立差分测试检查。

本地 SDK 测试没有复现平台 1.9 十秒级退步。实际镜像源码和强制 C++ 加载均已核对，但没有平台阶段日志，不能证明额外耗时的唯一原因，也不能保证任何服务器上都会加速。

本版与1.6、1.10、1.12的后续同场对照，以及完整请求、CPU、模型等待、响应大小和失败记录，统一保存在完整项目的 `artifacts/v1.12/`；不将局部内核加速写成官方得分提升。

最终构建发现快照漏带round_optimizer.h，已补齐原始头文件。规范化断言源码路径后，重新编译的二进制与已完成测试的二进制逐字节一致。完整项目保留首次失败日志和 snapshot-build-reconciliation.json 核对证据；最终源码包已包含该头文件。
