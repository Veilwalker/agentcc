# AgentCC 1.5：容量约束下的可验证转发程序

当前设计为revision-05。目标同时包括通信成本、完整求解时延和模型成本。LLM提出有限的跨轮转发程序；确定性程序负责合法构造、路径搜索、精确编译和独立验收。没有训练神经网络，也不宣称全局最优、模型必然胜过传统优化器或已证明长注意力机制的优势。

## 1. 当前输入定义问题

节点是rank和交换机，边是实际输入声明的有向连接。共享资源、容量和成员边也完全取自输入；名称只作标识，不能补出不存在的边。多卡共享交换机不能直接等分带宽：应对每项已声明资源累计实际占用。资源可重叠，同一路径也可多次占用同一资源。

设路径p使用边或资源j的次数为a[j,p]，容量为C[j]，承载字节为b[p]，则B[j]=Σ a[j,p]b[p]。公开时间模型为：

```text
T_round = max(
    max_packet(路径开销 + 包字节数 × 路径各边倒带宽之和),
    最大路径开销 + max_edge_or_resource(B / C)
)
T_communication = Σ T_round
```

metrics用秒，本地诊断用微秒。容量决定每轮所需时间；不额外规定“一秒一轮”。权威是官方Judge，本地Replay按公开规范实现。[共享资源规范](materials/spec/SHARED_RESOURCES.md)、[输出约束](materials/spec/OUTPUT_FORMAT.md)

## 2. 从固定路径编辑扩展到跨轮程序

旧1.5让模型编辑初解的少量路径分流，同时运行完整程序优化。该流程是本项目的工程选择，不是师兄论文的指定架构；实验证明模型动作常被后续路径搜索覆盖，净贡献较小。仅换提示词不能消除其邻域限制。

本轮把可变项增加到**什么时候转发**。先从合法初解建立轮初持有状态，选取最后五个可编辑复制轮作为有界窗口，计算每个窗口提前一半和全部就绪原子的实际单独收益、前后两轮时间以及有向边/共享容量摘要。窗口选择按结构和状态执行，不按拓扑名称分派。

模型输出整数向量k，每项只能取0、1、2：不改、提前一半、提前全部。若一个实际包有m个就绪原子，则选取其既有顺序前ceil(m×k/2)个。原子不拆分，0不产生动作。半量是每包比例，不能等同于全局字节量恰好一半。

指令的形式含义是：

```text
advance_ready_copy(round=r, proportion=k/2)
```

该指令绑定当前任务、实际拓扑和轮数，**预先声明在最终有效方案上重新解析**。它不是“把初解第N个包直接搬过去”。程序搜索改变rank次序或包边界后，编译器重新计算实际轮初持有状态，按同一轮次和同一比例产生具体动作；不会代模型更改数量、搜索其它数量或挑选其中有利的子集。若轮数不兼容、格式错误或动作组合无效，整个程序拒绝。

这使模型与程序可以并行：

```text
合法初解 → 容量摘要 → LLM转发程序 ───────────┐
                   → 确定性构造/改路/分包 ──┴→ 具体编译 → 完整Replay → 比较
```

控制分支不枚举跨轮比例，模型增加了一个实际影响调度的决策维度。程序仍进行必要的控制计算；不能宣称模型消除了这部分计算。初解统计与最终方案可能不同，模型投影存在偏差，回放接受条件负责保护通信质量。

## 3. 编译与正确性边界

对原方案S中第r轮的一条copy(s,d,A,p)，只允许选择在第r−1轮开始前已经由s持有的完整原子A'。新方案把copy(s,d,A',p)放到第r−1轮，原动作保留A\A'。发送者、接收者、路径和原子内容保持不变；模型改变的是轮次及搬移量。

AllGather的原子是原始分片。AllReduce只移动完整规约结果的copy，reduce动作完全不动，部分贡献表达式不能当作独立结果提前复制。当前编译器对所有规则使用同一份原方案的轮初状态，不允许利用“本次规则刚收到的数据”在同轮继续发送。

单个动作保留每个目标的接收原子多重集合，且满足提前轮初的源持有约束。这是必要条件；尤其AllReduce的贡献集合、重复接收和混合阶段仍须完整回放，不能仅靠局部条件宣布正确。

[src/forward_edit.py](src/forward_edit.py)编译整个提案，先根据已验证控制方案的逐轮时间，精确重算改变的轮。成本未改善时可直接拒绝；可能改善的候选仍须由[src/replay.py](src/replay.py)完整独立验证路径方向、资源、轮初依赖、重复接收、完整贡献、最终目标和非空轮数。成本筛选只能拒绝，不能替代赢家的语义校验。增加传输条数受到预算限制。不允许通过删去违规动作“修复”模型提案。

设有效控制方案为C，模型程序编译结果为F。仅当F完整合法且T(F)<T(C)才返回F，否则返回C。因此在本地时间模型正确的前提下，单次请求的最终通信成本不劣于该次控制方案。该结论**不保证**跨版本无退步、官方总分提高或求解时间不增加。旧版的模型路径编辑可能找到本轮窗口之外的收益。

## 4. 开销、稳定性与接受政策

确定性控制沿用1.5的有限构造、结构复用、已有路径优化、有预算联合分流和完整原子分包。路径与容量优化的逻辑没有为了保留模型动作而放宽。模型请求通常一次，温度0，输出最多64 Token；真实请求和原始回复留证，凭据不进入模型输入或产物。

请求时间近似为pre + max(LLM,控制计算) + post，但最终评价必须直接测完整SDK请求，包括解析、输出和完整响应读取。模型总时长包含与CPU重叠的部分，不能直接当成可节省的时间。Token影响网络请求、处理和生成开销，无法从历史相关性推出统一“每千Token几分”。

固定工作量与确定性原子顺序限制程序波动；温度0不能消除模型和服务差异。不同回复经相同编译规则和完整验收处理。必须分别比较原始回复、最终调度哈希与请求时间，不能把变化一概归因于服务器。

提示是有限投影：代表性有向边、共享资源和四位有效数字，不是完整拓扑的无损编码。完整输入仍参与程序计算和最终回放。用实际输入扰动测试这一依赖，而不是把实例名称放进提示。

新增两项保持语义的本地计算优化：

- **按目标查询计算末跳。** rank不能作为路径中继。因此，给定源rank的最短路可分为“源到交换机的最短路”与“交换机到目标rank的最后一条边”，再与源到目标的直连边比较。只在查询该目标时计算末跳，不必为每次交换机扩展扫描所有rank出口。保留有向边、原权重、等价路径的原有稳定排序和独立缓存淘汰规则。有限权重仍逐项检查。45,600次新旧路径对照另加独立Bellman-Ford测试支持实现一致性；这不是新的通信策略。
- **用计数预览候选。** 提示中的半量/全量时间只需要当前路径、就绪原子数和每包字节量。直接累计两个受影响轮的负载，可避免构造十份临时调度。零字节包不产生启动开销；最终模型提案依然真正编译并完整回放。14份提示与改动前逐项一致。

这两项优化减少调用前和控制搜索的计算，不通过缩减候选、忽略资源或减少校验换取速度。

## 5. 证据应能证伪

本轮提供以下对照，不把不同口径混合：

- 官方SDK真实模型新旧对照：通信、完整请求、CPU、输入/输出Token、响应字节，轮换顺序，多次重复。
- 固定真实回复与零编辑：同一个有效控制、同样编译，直接测量模型程序带来的增量；重复回复应产生相同调度。
- 同目录贪心与枚举：窗口最多5个，最多243种比例组合，可离线核对模型是否接近有限目录最优。即使相等，也只说明选对这份小目录，不证明LLM比枚举快或更聪明。
- 同名输入改变边、方向、带宽和重叠资源：检查重新计算、提示变化、语义正确性及相对控制不退化。合成回复不计作真实模型成功。

`model_edit.accepted/selected`表示最终编译方案严格胜过控制；记录实际提前原子数、模型原始数量、控制/最终耗时、输入与控制方案哈希、编译原子数，并保留最终完整答案。最终独立消融检验模型净贡献，不能把全部程序优化归功于LLM。

## 6. 师兄建议与文献的实际作用

[SmartCCL论文](materials/research/2026085860-1.txt)主要针对AllGather：神经网络生成逐步转发动作，中央贪心模块消除冗余并调整步长。这里采用它的容量建模、提案与中央校验分离，以及从时间安排中去除无效等待的思路。没有训练其网络，没有直接复现论文性能结论，也没有把AllGather结论自动推广到AllReduce。

本轮用“确定性合法控制 + LLM转发程序 + 独立验收”探索替代人工/贪心后处理的一部分。模型实际决定数据搬移比例，程序负责精确算术和正确性。这比给一个算法名称更具体，也保留了通过知识判断组合改动的空间。当前只有五个窗口，不能据此宣传已经证实长上下文或长注意力带来优势。

[TACCL](https://www.usenix.org/conference/nsdi23/presentation/shah)使用通信草图约束并引导搜索，启发了将高层意图编译为具体动作；[TECCL](https://arxiv.org/abs/2305.13479)提供容量与多商品流建模视角。这里的有限指令、持有状态编译、请求内并行和验收政策是本项目实现，不借用上述论文的最优性保证。

固定最后五个复制轮仍可能陷入局部最优；归约结构、跨更多轮的改写、不同发送者和更丰富的资源选择仍在当前生产邻域之外。已试验更换发送者、模型后置、固定包目录迁移、不同窗口与提前距离、混合基数阶段合并、一次输出两/三份程序和多种提示，原始记录均保留。阶段合并在部分公开输入有潜力，但在其它输入明显变差，尚无已验证的通用在线收益政策；没有按拓扑名字套用最佳离线选项。没有稳定综合收益的方向不进入生产。

专家和Token复核合占综合成绩30%，不等同于“专家主观分单独占30%”。本项目强调能核验的实现与对照，不以叙事替代实测。
