# 1.5 revision-05 验证与取舍

本轮主基准是**已发布1.4**，不是尚未平台测试的1.5。保留本轮候选：它在公开样例的完整请求、通信和总Token上有综合收益，但有逐例退化与未解决的模型波动。没有把本地结果换算成官方分数。

## 模型作用与稳定性

[稳定性原始记录](artifacts/v1.5/analysis/revision-05/stability.json) · [固定回复、零编辑及243组合审计](artifacts/v1.5/analysis/revision-05/fixed-replies.json)

42次新版请求中，**29次模型程序严格改善最终控制方案并被采用**。模型实际决定最多五个复制轮的搬移比例，编译器不会替换为自己搜索出的更好比例。控制分支不搜索该比例向量。采用条件比较整个有效方案，不能为了保留模型动作接受退化。

13/14样例的三次模型数量向量及最终调度哈希都相同。Uneven AG出现[0,2,0,0,0]和[2,2,0,0,0]：前者得到18,449.176µs，后者整个组合不改善，返回18,570.192µs的有效控制。这是模型决策差异，不能全部解释为服务器波动。相同回复重放全部得到相同调度；非法回复、零编辑与输入不变性检查也通过。

固定审计逐例枚举五轮窗口的243种组合，共3,402个有限目录候选成本；各例目录最优解再执行完整Replay。它仅是离线审计，不在生产中按样例套用答案。模型并不总是胜过贪心或命中目录最优：Mesh AG距离该目录最好结果仍约5.74%，Mesh AR约1.55%。本版不能宣称LLM优于所有传统优化器、全局最优或已证明长注意力的优势。

模型时长的全部42次平均为1.755秒，完整请求平均为2.449秒，两者总量比约71.7%；其中大部分模型等待与程序计算重叠。未被覆盖的等待平均约0.595秒，不能把1.755秒全部视为可节省量，也不能从历史Token相关性计算统一“每千Token几分”。接口没有返回reasoning_content或推理Token细分，缺失字段不能证明服务器关闭了思考模式。

- 4次变更拓扑的真实SDK/模型补测全部有效，保留原实例ID但提示均重新变化；一份模型提案改善当前控制并被采用：[实际调用](artifacts/v1.5/runs/revision-05/live-mutations/)、[输入与决策核对](artifacts/v1.5/analysis/revision-05/live-mutation-audit.json)。这组只用于补充有效性证据，不混入性能主对照。
- 45,600次新旧路径查询完全一致，覆盖14份公开输入及200份随机有向/重叠资源输入：[路径核对](artifacts/v1.5/analysis/revision-05/route-equivalence.json)。独立Bellman-Ford检查另在单元测试中。
- 无临时调度副本的容量预览与旧实现生成的14份模型输入完全一致，各例准备CPU均减少：[核对](artifacts/v1.5/analysis/revision-05/preview-equivalence.json)。这是一轮局部测量，不替代完整请求数据。

## 探索过哪些方向

研究记录不并入上面的84次主对照，不用表现最好的一次替换失败记录。

| 方向 | 证据 | 决定 |
| --- | --- | --- |
| 窗口3/5/8、提前1/2/3轮、半量/全量、混合基数阶段合并 | [476个候选](artifacts/v1.5/analysis/revision-05/structural-sweep.json) | 全部有效，但跨拓扑取舍明显。生产采用五轮、提前一轮；阶段合并暂未找到可靠通用接受流程。 |
| 单份五轮指令与显式半量/全量收益 | [宽窗口](artifacts/v1.5/runs/revision-05/wider-pilot/)、[显式收益](artifacts/v1.5/runs/revision-05/lazy-gain-pilot/)、[压缩字段](artifacts/v1.5/runs/revision-05/compact-pilot/) | 保留简短单程序及明确的收益数值，避免模型做大量重复算术。 |
| 一次输出三份程序 | [原始失败](artifacts/v1.5/runs/revision-05/portfolio-pilot/) | 出现长度错误、截断和重复回复；最终方案依靠控制回退有效，不表示模型协议成功。未采用。 |
| 具名主/备双程序 | [试验](artifacts/v1.5/runs/revision-05/two-plans-pilot/) | 等待增加，收益不稳定，未采用。 |
| 邻接编辑联合成本摘要 | [8次真实对照](artifacts/v1.5/runs/revision-05/pair-cost-pilot/) | Mesh无额外收益，Sparse AG丢失收益，四例请求都更慢。1.5.5仅为研究原型标签，未发布。 |
| 按需末跳求解、计数方式预览 | 路径与预览核对、完整84次对照 | 不减少候选或校验，进入当前代码。 |

476个离线候选是每例分别比较的研究，不是已经部署的自动策略。Clos的阶段合并有潜力，但其它拓扑明显回退。未来可研究更可靠的结构生成与模型上下文；不能把离线各例最优选项按名字固化到提交代码。

师兄论文在本项目中的实际作用、容量公式和编译正确性边界见[THEORY.md](THEORY.md)。原架构及其后续取舍是本项目的工程设计，不是师兄指定的流程。没有训练或运行神经网络；官方运行时与非root入口保持不变。
