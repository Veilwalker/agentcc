# AgentCC 1.7 验证报告

## 结论：通信改善，完整请求仍有明显代价

与冻结的 1.6 在相同公开输入上交替运行，**11 例通信改善、2 例持平、1 例小幅回退，通信几何平均加速 1.157 倍**。Mesh2D AR 降低 43.06%，Fullmesh Clos AR 降低 38.97%，CloudMatrix AG/AR 分别降低 5.19% / 11.89%。这不是所有指标都优于 1.6 的版本。

**完整请求中位数的样例平均从 3.685 增至 5.620 秒，增加 1.935 秒（52.5%）；14 例请求均更慢。** CPU 从 2.533 增至 4.152 秒，平均响应体从约 0.964 MB 增至 1.318 MB。新增容量预览、分流编译和代码生成均有代价，不能全部归因于服务器。

本轮新版 42 次实际请求共 17,730 Token，折合每 14 例 **5,910 Token**；旧版为 5,145.3。这里是实际总量除以三，不是挑选最好的一轮。逐例 Token 中位数相加为 5,920，两种统计不混用。通常一次调用；主对照没有触发第二次修正。

**1.7 尚未获得平台评分。** 1.6 最新平台分为 95.388，但公开样例的拓扑、数据大小和冻结评分锚点与平台不完全相同，不能将本地通信收益换算成提分，也不能承诺请求代价一定被抵消。保留 1.6 完整快照用于回退。

## 测量口径

[主对照原始记录](artifacts/v1.7/runs/release-sdk/summary.json) · [交互报告](artifacts/v1.7/reports/comparison/report.html) · [机器可读报告](artifacts/v1.7/reports/comparison/report.json)。14 个公开样例 × 1.6/1.7 × 各三次，共 **84 次真实模型、官方 SDK 完整请求**，全部通过本地独立 Replay。先逐例取三次中位数，再对 14 例等权；不挑最快一次、不把探索阶段混入发布统计。

主测量期间没有并行运行其他 CPU 实验。限制为单 CPU 亲和、1 GiB 地址空间，不冒充 Docker cgroup。使用未经修改的官方 AgentHack SDK、进程内 HTTP 测试传输，计时直到完整响应 JSON 解析完成，包含模型等待、搜索、编译、回放和序列化；不含跨服务器传输和官方 Judge。源码在主对照前后哈希一致，后续只完善测试与文档，生产代码保持相同。

三次重复不足以估计 P95 或证明统计显著性。历史截图不能与这组本地结果直接混合比较；不同规则的官方成绩也不直接相减。

## LLM 的实际作用与消融

旧版模型主要改写固定小区段。新版模型生成搜索循环或完整函数，在本次真实容量表上执行，搜索跨区段组合；有错或明显次优时最多反馈一次。路径目录、容量计算、原子编译、Replay 仍是工程模块。模型生成的是限定接口下的搜索核心，不是自由设计完整求解器。

[真实生成代码与执行证据](artifacts/v1.7/reports/model-code-evidence.json)保留提示、原始模型输出、代码哈希、当前输入哈希、成本表、执行结果与选择原因。[14 例固定代码重放与消融](artifacts/v1.7/analysis/release-fixed-code.json)不访问模型；每例两次执行同一已记录代码，编译调度一致、预测成本与 Replay 一致，最终答案与主对照对应记录一致。

42 次新版请求全部生成有效代码，并达到**保留阶段空间**的数值最小成本；其中 **27 次（9 个样例）**严格改善本次控制并进入最终答案。其余 15 次提案相等或较差，被拒绝。这不等于模型在物理网络上取得全局最优，也不证明模型优于同空间手写 DP。

以下均为同次固定代码消融的 μs，不混入不同随机控制：

| 公开样例 | 含确定性保底的控制 | 模型代码候选 | 结论 |
| --- | ---: | ---: | --- |
| cloudmatrix/ag | 7161.201 | 6833.157 | 模型扩展搜索带来额外收益 |
| cloudmatrix/ar | 121.894 | 116.701 | 模型扩展搜索带来额外收益 |
| fullmesh_clos/ar | 55.325 | 55.325 | 大幅改进主要来自保底，模型无额外改善 |
| mesh2d/ar | 54.322 | 54.322 | 大幅改进主要来自保底，模型无额外改善 |

| directed_ring/ag | 18304.600 | 25211.816 | 拒绝模型候选，保留控制 |

模型扩展空间使用容量预览与分流模块，不能将这些共同产生的收益全部归因于语言模型知识。审计器可算出有限空间的数值最小成本，仅用于验证/反馈，不生成替代模型答案。没有为了保留模型动作而接受更慢调度。

## 时间、Token 与随机性

[稳定性记录](artifacts/v1.7/analysis/release-stability.json)：新版 14 例的三次真实请求均得到相同最终调度和通信时间，其中 9 例出现不同生成源码。旧版有 5 例最终调度变化。不同程序写法可以计算相同最优阶段，确定性保底也有作用；这只是本轮观测，不是温度 0 的确定性保证。

模型时长的逐例中位数平均：1.6 为 **2.392 秒**，1.7 为 **5.045 秒**；未被本地计算覆盖的等待分别为 **1.141 / 1.447 秒**。模型与本地工作重叠，不能将前者直接加到 CPU 或从请求时长中相减。额外 CPU 开销约 1.620 秒同样重要。

接口返回的模型别名为 `deepseek_v4`，本轮没有独立 `reasoning_content` 字段；**缺少字段不能证明内部思考模式关闭**。没有从 Token 总量推导统一 token/s，也没有宣称“每减少 1000 Token 增加固定分数”。输入预填充、输出生成、服务排队和计算重叠都影响延迟。

## 正确性、扰动与反馈覆盖

- **432 项自动回归通过**，日志：[unit-final.log](artifacts/v1.7/reports/unit-final.log)。覆盖现有通信语义、重叠共享资源、路径重复占用、模型代码解释、有限空间最优、轮数限制、输入不可变、资源上限与官方运行时。
- **84/84 主对照有效**；官方 SDK 真实模型调用，代码与运行记录可追溯。
- **42/42 离线拓扑扰动有效**：[mutations.json](artifacts/v1.7/analysis/mutations.json)。保留实例名，改变方向、边、带宽、资源容量/成员；36 例执行已记录模型代码，6 例 NVLink-like 因不存在阶段所需合法路径而明确回退，未声称执行新算法。这组零模型调用，检查工程适应性，不证明模型重新分析能力。
- **4/4 真实补充请求有效**：[live-changes](artifacts/v1.7/runs/live-changes/summary.json)。2 个实际图扰动、2 个轮数紧约束，4 次真实调用、1,856 Token。紧约束走完整函数生成协议；这组没有旧版对照，不用于宣称加速。
- **14/14 固定真实代码重放有效**，重复编译哈希一致，独立 Replay 与预览成本相符。
- 本轮主对照与真实补充均未自然触发修复；“错误代码 → 反馈 → 修正”通过模拟错误回复的回归测试验证，**不冒充真实线上失败修复记录**。

首次扰动审计在 27 个记录后停止：测试工具把无阶段表回退的空指纹误当成输入未变化。原始记录保留为 [mutations-harness-failure.json](artifacts/v1.7/analysis/mutations-harness-failure.json)。修正后重新完整执行 42 例，分别核对实际输入、代码执行和回退原因；不是忽略失败项继续报全通过。

## 规则与交付边界

正式通知：[25/50/25、六分钟公告](materials/notices/scoring-2026-11-06.md)。达到 360000 ms 或没有有效解记零，14 例取算术平均，Token 不直接计入自动榜。通知对“三分钟内分数差异”的说明是历史重算兼容，不代表前三分钟搜索免费。

用户转发的 [LLM 过程导向](materials/notices/llm-process-guidance-2026-11-06.md)要求提前保留生成、修改、执行反馈等过程记录，详细评分和生效安排仍待公布。本项目记录格式尚未获官方认证；专家与 Token 复核合占综合 30%，不能把整项都叫专家主观分。

阶段空间适用 2～512 个、数量为 2 的幂的 rank，宽度最多三维、保留有限路径与布局、固定当前切分。其他规模沿用旧模型编辑流程；阶段缺路明确回退。仍存在未覆盖的通信结构，不声称全局最优。

[THEORY.md](THEORY.md)说明容量、状态不变量、师兄建议与文献联系。本版没有训练神经网络，未要求额外 C++ 编译器或 GPU。没有执行 Docker、导出镜像或上传平台。源代码和使用方法见 [README.md](README.md)，旧 1.6 发布源码保持原样。
