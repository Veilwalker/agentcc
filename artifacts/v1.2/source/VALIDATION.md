# 1.2 验证与优化记录

规则版本：`agentcc-256-20261101-v22`。代码版本：1.2。测试日期：2026-11-03（Asia/Shanghai）。1.1 的平台历史自动分为 92.1；本版尚未提交平台，没有新的官方成绩。

## 最终回归结果

- **184 项自动测试全部通过**，覆盖官方 SDK、依赖与规约语义、容量计费、具体编辑、轮次组合、无效提案拒绝、冻结动作保留、时限与并发隔离。
- 冻结源码后，**1.2 共 23 次真实模型加官方 SDK 请求全部有效**：14 个公开 256-rank 输入，2 个小例，1 个小例容量变更，4 个同名大拓扑变体，以及 2 次 mesh 同目录消融。合计 21 个不同输入，每次 SDK 均记录 1 次真实模型调用，最终方案独立本地 Replay 通过。上述 23 次合计 46,928 Token。
- 同一测试时段另运行 14 次归档 1.1，对同一输入交替新旧执行顺序。**28 次配对请求全部有效**，每次 1 次模型调用。
- **42 个完整服务输入扰动回归全部有效**。这组使用明确标记的模拟模型响应，不联网，也不计入真实模型能力的证据。
- 最终测试前后生产源码 SHA-256 一致。实际运行入口始终是未经修改的官方 SDK `AgentRuntime(MyAgent()).run()`。

这里的“有效”均指按公开规则实现的本地 Replay，不冒充官方 Judge 结论。探索阶段的早期调用和结果另外保存在 `artifacts/v1.2/`，未混入上述冻结源码后的回归汇总。

## 模型的实际贡献与对照

7/14 个大例有模型提出的正数量动作被选中并保留到最终方案。另 6 例返回全零数量，1 例提出了正数量但没有改善；均明确记录拒绝原因并保留有效方案，没有替模型补造动作。最终改路固定的是已选中的移动前缀，仍可优化其余传输，不把后续全部收益归因于模型。

模型参与的完整链路可查：当前任务与容量输入 → 实际请求 → 原始回复 → 无损数量解码 → 原子分片与路径编辑 → 联合候选 Replay → 逐轮验收 → 与独立对照逐轮组合 → 保留移动前缀的最终改路。详细不变量与容量推导见 [THEORY.md](THEORY.md)。

另外两次真实 mesh 请求捕获了模型实际看到的冻结基线和编辑目录，待响应返回后，在相同目录上运行有 1 秒搜索预算的确定性整数数量优化。它与模型使用相同动作范围和整轮恢复规则；确定性方法可精确计算完整路径成本，模型看到生产中的紧凑投影。下表分别报告模型编辑与最终服务结果：

| 样例 | 冻结基线 μs | 模型编辑验收后 μs | 同目录确定性优化 μs | 完整服务最终 μs |
| --- | ---: | ---: | ---: | ---: |
| mesh2d/ag | 11419.816 | 10542.888 | 8024.097 | 7697.511 |
| mesh2d/ar | 217.901 | 217.901 | 165.306 | 159.848 |

AG 的真实模型动作被采用并保留；AR 返回全零，没有可采用动作。**两例中，同目录确定性优化都优于模型提案。** 因此目前证据支持“模型可参与具体编辑并产生改善”，不支持“LLM 已胜过确定性优化”或“长注意力带来额外收益”。完整服务还有逐轮组合与更广路径搜索，不能把最后一列全部计为模型贡献。消融原始请求、上下文与对照方案见 [真实同目录实验](artifacts/v1.2/live-ablation-final/summary.json)。

## 规则与异常检查

重新核对了当前 V22 题目、输入、输出、共享资源规范及官方运行时补充要求。实现按实际有向边与资源成员计算负载，不平均切分交换机带宽，不把固定时间步的容量当成官方轮次硬上限。所有编辑只移动已有完整原子分片；AllReduce 的贡献表达式不拆开。切分、初始与最终持有关系、数据依赖及轮数约束继续完整验证。

本轮修正了提示示例中的基线占位文字：模型曾原样返回 `copy problem.base`，严格校验正确拒绝，但损失了编辑机会。最终提示直接嵌入当前基线标识，客户端仍不修复错误编号。冻结后的 14 个公开大例全部返回与当前基线匹配的编号；相应回归测试纳入 184 项测试。

逐轮组合显式处理空轮与 Replay 非空轮指标的索引差异；只冻结实际选中轮次中的模型动作。独立审查核对了 14 份最终响应的唯一胜出记录、调用次数、哈希、最终成本及选择历史，7 个模型入选案例的 376 条冻结传输路径和移动数量与编辑清单对应。

42 个最终扰动回归保留实例名，改变方向、连接、容量和重叠资源；实际运行服务、提示构造、响应解码与编辑编译。包含 11 次半量、11 次八成量、10 次未知组以及 10 次无改动响应。18 次编辑通过基线验收，14 次被选中，14 次的完整移动前缀在最终方案中逐条保留。全部原始输入不被修改，模型输入的实际语义随拓扑变化，最终只有一条选中历史记录，源码始终未变。原始结果见 [42 个扰动回归](artifacts/mutations-v1.2-final.json)。这组平均 1.934 秒、最大 3.998 秒，未含模型网络耗时；峰值 RSS 93.28 MiB。

7 个真实小例和大拓扑变体也重新调用模型、重新解析实际输入。该组进程峰值 RSS 136.95 MiB；不能从这组公开输入推断任意输入的内存上界。

## 验证边界

宿主机 Python 3.10，官方基础镜像 Python 3.11；宿主机测试使用从官方基础镜像提取的原版 SDK。测试通过 SDK 原始 ASGI 应用的进程内 HTTP 传输执行，没有启动提交镜像。单 CPU 亲和性与 1024 MiB 地址空间限制不等于 Docker 的 CPU 配额、内存 cgroup 与 256 pids 限制。

公开样例和变形输入不是平台冻结题库；材料未附官方 Judge 可执行程序以及冻结的 `L/U/t_good`，因此不能计算新官方得分。模型输出、网络延时和软预算候选可能变化；保留 1.1 供比较，下一次正式打榜才能验证综合取舍。
